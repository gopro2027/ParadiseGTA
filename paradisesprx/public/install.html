Install Wizard

Installs your Key.txt, ParadiseGTA.sprx and the EBOOT.BIN onto your PS3 over your home network. Your PC and PS3 need to be on the same network.

Alternatively you can download and install the files manually.

{ 5. Install }

Uses webMAN MOD's web commands, so nothing gets installed on your PC. Each step opens your PS3's webMAN page in a small window. Do them in order.

First, turn on webMAN's admin mode. webMAN starts in a restricted mode that answers these commands with "400 Bad Request ... ADMIN disabled". On the PS3, hold L2 + R2 and press TRIANGLE. One beep and an "ADMIN enabled" message means it's on. Two beeps means you just turned it off, so press the combo again. It switches back off when the PS3 restarts.

The PS3 has to be on the XMB (not in a game) with webMAN MOD running. If nothing happens when you click a step, check that your browser allows popups for this site. If webMAN keeps refusing, use the FTP installer tab instead, which doesn't need admin mode.
