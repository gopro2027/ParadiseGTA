The Paradise GTA V mod menu,
now open source and free.

Paradise SPRX is a GTA V mod menu for PS3. Paid keys are gone. Anyone can generate a key for free and use the menu.

Get a free key How to install

1. Get a key

Generate a key on the free key page and download the Key.txt file.

The first console that uses a key is registered to it. You can reset that from the key page.

2. Copy it to your PS3

Put Key.txt in /dev_hdd0/tmp/gopro_2027/. The key is case sensitive.

The menu creates the folder the first time it runs.

3. Load the SPRX

Load ParadiseGTA.sprx into GTA V with your usual SPRX loader. Wait for the "Welcome to Paradise!" message before signing in.

Downloads

Build the SPRX yourself from the source code, or use the build published on this site if there is one. The other files are downloaded by the menu automatically when needed.
