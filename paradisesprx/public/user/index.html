Paradise GTA

Notes before you install:

  • Make sure Cobra mode is enabled. This is needed for all Paradise named mod menus to run.
  • Language support instructions can be found here.

HEN specific installation notes:

  • Make sure you are on the latest HEN version with the latest version of webMAN. Some old versions may not work.
  • If you patch syscalls and delete history with webMAN, please leave PS3MAPI enabled like in this picture, or you will blackscreen on load.

Install (DEX and HEN):

  1. Get the SPRX from the Downloads tab and your Key.txt from the free key page.
  2. Put an EBOOT.BIN that loads SPRX plugins at /dev_hdd0/game/BLES01807/USRDIR/EBOOT.BIN (delete or rename/backup the old EBOOT.BIN).
  3. Put the ParadiseGTA.sprx and Key.txt in your /dev_hdd0/tmp/ folder. Key.txt also works in /dev_hdd0/tmp/gopro_2027/.
  4. Run GTA V and it should say "Welcome To Paradise!" (along with some other messages on the first load).
    If it says "Key length short!" just reload the game. Sometimes that happens on the first run.

Post-installation freeze issues help:

  • Paradise, by default, is incompatible with some update.rpf's. If you get a freeze during the loading screens, try signing out of PSN, then loading GTA. If that fixes the freeze, go to the settings submenu and select 'Un-Install Paradise Script Menus'. A more technical fix is to modify gameconfig.xml.
  • Make sure you are on DEX (or HEN, CEX should convert to DEX). Run the 'Rebug Toolbox' homebrew and click 'System Information'. Make sure 'LV2 Kernel' and 'Target Type' both say 'DEX'.
  • Furthermore, make sure you are using BLES and have COBRA enabled.

Prebuilt structures for the Forge Menu.

How to spawn a creation file:

  1. Download the creation file and put it in the /dev_hdd0/tmp/gopro_2027/ folder.
  2. Go in GTA to your desired location.
  3. Go to Forge Menu -> Creation Menu.
  4. Click Load Creation and type the filename (without the .creation part).
  5. Click Spawn Creation and wait a moment for all the objects to spawn.
